2. Fundamental Computer Network Concepts

A computer network connects devices so that they can exchange data and resources.

IP Address

A unique logical address used to identify a device on a network.

Router

Connects different networks and forwards data packets.

Switch

Connects devices within a local network.

Protocol

A set of communication rules such as TCP/IP and HTTP.

5. Web Browsers and Web Servers

Web Browser

A client application used to request, receive and display web pages.

  • Chrome
  • Firefox
  • Safari
  • Edge

Web Server

A system that stores and delivers web resources to clients.

  • HTML/CSS/JS files
  • Images
  • Applications
  • Database responses

7. Client-Side vs Server-Side Scripting

Client-Side

  • Runs in the browser.
  • Uses HTML, CSS and JavaScript.
  • Handles user interaction and UI behavior.
  • Provides quick browser-side validation.

Server-Side

  • Runs on the server.
  • Uses technologies such as Java, Python, PHP or Node.js.
  • Handles databases and business logic.
  • Generates dynamic responses.
